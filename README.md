# 音视频转文字

一个在Windows和macOS本地运行的音视频转文字工具。既可以粘贴B站分享文本、视频链接或BV号，也可以上传本地音频或视频文件；程序会统一准备MP3音频，调用两个由用户配置的AI模型，最终生成便于阅读和下载的Markdown文稿。

项目没有账号系统和服务端数据库，适合个人学习整理、研究或处理已获授权的视频。当前仅处理所选分P，不支持绕过付费、会员、私密或其他受限内容。

## 项目工作流

1. **识别输入来源**：解析B站分享文本、短链、视频链接或BV号；也可通过输入框右侧的 `+` 选择本地音频或视频文件。
2. **获取访问凭据**：仅处理B站链接时使用Playwright获取必要Cookie；本地上传任务不需要B站登录态。
3. **获取字幕和视频信息**：B站任务会查找并清理字幕；本地上传任务直接跳过该阶段，并在统一提示词的字幕板块写入无原生字幕说明。
4. **处理音频**：B站任务下载音频流，本地任务读取上传文件；两者都用FFmpeg转为MP3，再按统一规则切片。
5. **音频转文字**：音频转文字模型接收MP3或MP3切片，支持OpenAI-compatible多模态音频和AIStudioToAPI Gemini Files API。
6. **合并转写稿**：按切片顺序合并结果，并尝试消除相邻切片的重合文字。
7. **优化文稿**：文稿优化模型对照B站字幕或本地文件占位说明与AI音频转写稿，校对错字、补全标点并生成Markdown。
8. **本地保存**：原生HTML/CSS/JavaScript前端使用IndexedDB保存设置和历史；FastAPI后端负责任务调度、进度、错误重试和临时文件清理。

主要技术：Python、FastAPI、Uvicorn、原生HTML/CSS/JavaScript、IndexedDB、Playwright、yt-dlp、httpx、FFmpeg。

## 功能介绍

- 支持完整分享文本、B站链接、`b23.tv` 短链和BV号。
- 支持上传MP4、MKV、MOV、AVI、WebM、MP3、WAV、M4A、AAC、FLAC、OGG、Opus等常见本地视频和音频格式。
- 获取视频标题、当前分P、时长、B站字幕和音频。
- 清理JSON、VTT等字幕中的时间轴和元信息。
- 自动转换MP3、长音频切片和转写失败重试。
- 无字幕时可由用户确认后跳过字幕，继续使用音频转写。
- 展示任务进度、当前步骤和脱敏日志，可取消任务。
- 展示并下载最终Markdown，也可复制Markdown原文。
- 可分别下载清理后的字幕、AI音频转写稿和日志TXT。
- 保存、搜索、恢复和删除历史记录。
- 支持本地数据全量导出、导入和清空。

## 下载与本地运行

### 1. 下载ZIP

1. 打开 [GitHub仓库](https://github.com/Naroahgany/Video2text)。
2. 点击 `Code` → `Download ZIP`。
3. 下载完成后解压到桌面或其他有写入权限的目录。

请完整解压后再运行，不要直接在压缩包预览窗口中启动脚本。

### 2. Windows

1. 双击根目录中的 `start-windows.bat`。
2. 保持弹出的控制台窗口开启。
3. 首次运行会自动检查或准备Python、项目虚拟环境、依赖、Playwright Chromium和FFmpeg。
4. 服务就绪后会自动打开浏览器。

### 3. macOS

1. 首次运行前，在“终端”进入项目目录并执行：

   ```bash
   chmod +x start-mac.command scripts/start-local.sh
   ```

2. 双击 `start-mac.command`。如果系统阻止打开，可右键该文件选择“打开”，或在“系统设置 → 隐私与安全性”中允许。
3. 保持终端窗口开启。若电脑没有可用的Python，脚本会下载并打开Python安装程序；安装完成后按终端提示继续。
4. 服务就绪后会自动打开浏览器。

### 4. 启动说明

- 默认地址是 `http://127.0.0.1:8000`。
- 如果8000端口已占用，程序会自动选择8001～8099中的可用端口。
- 健康检查地址是 `http://127.0.0.1:8000/api/health`；若使用了其他端口，请同步替换端口号。
- 首次启动需要下载运行依赖，耗时取决于网络；以后会复用项目 `runtime/` 中的本地环境和缓存。
- 关闭启动脚本的控制台或终端窗口即可停止本地服务。

启动脚本默认使用适合中国大陆网络直连的下载源。高级用户可在启动前通过 `PIP_INDEX_URL`、`VIDEO2TEXT_PYTHON_URL`、`PLAYWRIGHT_DOWNLOAD_HOST` 和 `PLAYWRIGHT_BROWSERS_PATH` 更换可访问的镜像或缓存目录。

## 使用指导

### 第一次使用：登录B站并自动获取Cookie

程序不会替你输入账号、密码或完成扫码，登录操作始终由你本人完成。

1. 首次打开页面时，点击“打开B站登录窗口”。
2. 在程序打开的独立Chromium窗口中，自行扫码或输入账号完成B站登录。
3. 确认窗口中已经显示登录状态，并保持这个B站窗口打开。
4. 回到工具页面，点击“提取并保存Cookie”。
5. 程序会自动读取登录状态，只保留以下6个字段并保存到当前浏览器的IndexedDB：

   `SESSDATA`、`bili_jct`、`DedeUserID`、`DedeUserID__ckMd5`、`bili_ticket`、`bili_ticket_expires`

6. 提取成功后，程序会关闭登录窗口并进入主页面。

如果之后出现Cookie失效、未登录、HTTP 403或HTTP 412，请打开右上角“设置 → 本地Cookie值 → 重新获取”，重新完成以上步骤。

### 配置两个模型

打开右上角“设置 → 模型配置”。两个模型用途不同，都需要配置。

| 配置 | 用途 | 要求 |
| --- | --- | --- |
| 音频转文字模型 | 直接读取MP3，把音频逐段转成文字 | 必须真正支持音频输入，普通纯文本模型不可用 |
| 文稿优化模型 | 对照B站字幕和音频转写稿，生成最终Markdown | 支持OpenAI-compatible Chat Completions的文本模型 |

音频转文字模型有两种识别方式：

- **OpenAI Compatible需要多模态模型**：通过 `/chat/completions` 发送Base64 MP3。`API Base URL` 通常填写到 `/v1`，例如 `https://api.example.com/v1`。模型必须支持 `audio_url` 音频内容。
- **AIStudioToAPI Gemini原生：Files API**：先上传MP3，再调用Gemini原生流式接口。`API Base URL` 填AIStudioToAPI服务根地址，例如 `http://localhost:7860`，不要手动加 `/v1/chat/completions`。

各字段填写方法：

| 字段 | 填写说明 |
| --- | --- |
| API Base URL | 你的模型服务地址；必须以 `http://` 或 `https://` 开头 |
| API Key | 模型服务商提供的密钥 |
| Model | 模型ID，可手动填写，也可先点击“获取模型”后选择 |
| Temperature | 建议从 `0`～`0.3` 开始，减少转写和校对时的自由发挥 |
| Stream | 建议保持开启，长内容返回更稳定 |

填写后分别点击两个模型卡片中的“保存配置”。“获取模型”只是读取服务商返回的模型列表，不能保证列表中的每个模型都支持音频；音频转文字模型仍需选择明确支持音频输入的型号。

### 开始转换

1. 在首页粘贴B站分享文本、视频链接或BV号；如果输入框为空，也可点击右侧的 `+` 选择本地音视频文件。
2. B站链接点击发送按钮开始；本地文件选择完成后会自动上传并创建任务。
3. 保持本地服务窗口和当前网页开启，等待任务完成。
4. 如果B站视频没有字幕，可按页面提示选择“跳过字幕继续”；本地上传任务会自动跳过字幕阶段。
5. 完成后可下载或复制Markdown，并可展开查看字幕、音频转写稿和完整日志。

长视频会产生多个模型请求，耗时、费用和成功率取决于视频长度、网络和模型服务商限制。当前多P视频只处理链接所指向的分P；如需处理其他分P，请分别提交对应链接。

## 数据隐私说明

- 模型配置、API Key、精简B站Cookie和历史记录保存在当前浏览器的IndexedDB中，不写入项目源码。
- B站完整Cookie不会返回前端或写入日志；本地专用登录Profile保存在 `runtime/browser-profile/`。
- 本地上传文件只暂存在任务独立临时目录中，任务完成、失败、取消或超时后会自动清理。
- API Key和精简Cookie只在任务需要时发送给本机FastAPI后端；后端不会把它们写入持久文件，并会对日志中的常见密钥格式进行脱敏。
- 音频和中间文件临时存放在 `data/temp/`，任务完成、失败、取消或被判定为abandoned后会尝试清理。
- 选择第三方模型服务时，音频、字幕或转写文本会发送到你填写的API服务商。请在使用前阅读该服务商的隐私政策和数据保留规则。
- “导出”文件包含模型配置、API Key、精简Cookie和历史正文，属于敏感备份。请勿发送给他人或上传到公共平台。
- 清除浏览器站点数据会删除本地设置和历史。迁移浏览器或电脑前，请先导出备份。

## 常见错误排查

| 问题 | 处理方法 |
| --- | --- |
| 首次启动长时间没有完成 | 首次运行需要安装依赖和Chromium。保持窗口开启并检查网络；失败后重新运行启动脚本会复用已下载内容 |
| Python下载或依赖安装失败 | 安装Python 3.10及以上版本（推荐3.12）后重试，或检查 `PIP_INDEX_URL`、`VIDEO2TEXT_PYTHON_URL` |
| Playwright Chromium缺失或损坏 | 关闭本地服务后重新运行启动脚本；同时检查 `PLAYWRIGHT_DOWNLOAD_HOST` 是否可访问 |
| FFmpeg不可用、MP3转换或切片失败 | 重新运行启动脚本；确认磁盘空间充足，也可手动安装FFmpeg并加入 `PATH` |
| Mac无法双击启动 | 执行 `chmod +x start-mac.command scripts/start-local.sh`，再右键 `start-mac.command` 选择“打开” |
| 页面显示“后端未连接” | 确认控制台/终端仍在运行，并访问当前端口的 `/api/health`；不要直接双击 `frontend/index.html` |
| B站登录窗口打不开 | 检查Playwright Chromium、网络和安全软件；关闭残留Chromium进程后重试 |
| Cookie提取不到 | 确认已在程序打开的独立B站窗口中登录，并保持窗口打开，再回到工具点击“提取并保存Cookie” |
| HTTP 403、HTTP 412、未登录或Cookie失效 | 在“设置 → 本地Cookie值”中重新获取Cookie，并先用普通公开视频测试 |
| 没有检测到字幕 | 视频可能没有UP主字幕或自动字幕，可按页面提示跳过字幕并仅使用音频转写 |
| 音频下载失败 | 先刷新Cookie；确认视频可正常播放且不是付费、会员、私密或受限内容 |
| API Base URL无效 | 必须以 `http://` 或 `https://` 开头；OpenAI-compatible通常填到 `/v1`，Gemini Files API填服务根地址 |
| API Key无效或无权限 | 核对密钥、余额、模型权限和服务商区域限制，再点击“获取模型”测试连接 |
| 音频转文字模型不支持音频 | 更换明确支持音频多模态的模型，或改用AIStudioToAPI Gemini Files API |
| 请求体过大、限流或超时 | 稍后重试，检查服务商的文件大小、并发和速率限制，必要时更换模型服务 |
| 文稿优化失败或输出被截断 | 换用上下文更长、输出上限更高的文本模型；程序会自动重试和续写，但仍受服务商限制 |
| 导入失败 | 仅导入由本工具导出的JSON，且不要手动修改文件结构；导入会覆盖当前全部本地数据 |
