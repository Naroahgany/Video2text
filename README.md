# B站视频转文字

一个在 Windows 和 macOS 本地运行的 B站视频转文字工具。粘贴 B站分享文本、视频链接或 BV 号后，程序会获取字幕和音频，调用两个由用户配置的 AI 模型，最终生成便于阅读和下载的 Markdown 文稿。

项目没有账号系统和服务端数据库，适合个人学习整理、研究或处理已获授权的视频。当前仅处理所选分P，不支持绕过付费、会员、私密或其他受限内容。

## 项目工作流

1. **识别视频**：从分享文本、`b23.tv` 短链、B站视频链接或 BV 号中提取目标视频和分P。
2. **获取访问凭据**：使用 Playwright 打开隔离的 B站登录窗口。用户自行登录后，程序只提取 6 个必要 Cookie 字段。
3. **获取字幕和视频信息**：通过 B站视频信息、播放器字幕、WBI 签名接口、页面初始化数据和 yt-dlp 等多条路径查找字幕，优先选择中文字幕。
4. **处理音频**：通过 B站 `playurl` 接口只下载音频流，再用 FFmpeg 转为 MP3。15 分钟以内不切片，15～30 分钟对半切分，超过 30 分钟按约 15 分钟切片并保留 30 秒重合。
5. **音频转文字**：第一模型接收 MP3 或 MP3 切片，支持 OpenAI-compatible 多模态音频和 AIStudioToAPI Gemini Files API。
6. **合并转写稿**：按切片顺序合并结果，并尝试消除相邻切片的重合文字。
7. **优化文稿**：第二模型对照 B站字幕和 AI 音频转写稿，校对错字、补全标点并生成 Markdown。
8. **本地保存**：原生 HTML/CSS/JavaScript 前端使用 IndexedDB 保存设置和历史；FastAPI 后端负责任务调度、进度、错误重试和临时文件清理。

主要技术：Python、FastAPI、Uvicorn、原生 HTML/CSS/JavaScript、IndexedDB、Playwright、yt-dlp、httpx、FFmpeg。

## 功能介绍

- 支持完整分享文本、B站链接、`b23.tv` 短链和 BV 号。
- 获取视频标题、当前分P、时长、B站字幕和音频。
- 清理 JSON、VTT 等字幕中的时间轴和元信息。
- 自动转换 MP3、长音频切片和转写失败重试。
- 无字幕时可由用户确认后跳过字幕，继续使用音频转写。
- 展示任务进度、当前步骤和脱敏日志，可取消任务。
- 展示并下载最终 Markdown，也可复制 Markdown 原文。
- 可分别下载清理后的字幕、AI 音频转写稿和日志 TXT。
- 保存、搜索、恢复和删除历史记录。
- 支持本地数据全量导出、导入和清空。

## 下载与本地运行

### 1. 下载 ZIP

1. 打开 [GitHub 仓库](https://github.com/Naroahgany/Video2text)。
2. 点击 `Code` → `Download ZIP`。
3. 下载完成后解压到桌面或其他有写入权限的目录。

请完整解压后再运行，不要直接在压缩包预览窗口中启动脚本。

### 2. Windows

1. 双击根目录中的 `start-windows.bat`。
2. 保持弹出的控制台窗口开启。
3. 首次运行会自动检查或准备 Python、项目虚拟环境、依赖、Playwright Chromium 和 FFmpeg。
4. 服务就绪后会自动打开浏览器。

### 3. macOS

1. 首次运行前，在“终端”进入项目目录并执行：

   ```bash
   chmod +x start-mac.command scripts/start-local.sh
   ```

2. 双击 `start-mac.command`。如果系统阻止打开，可右键该文件选择“打开”，或在“系统设置 → 隐私与安全性”中允许。
3. 保持终端窗口开启。若电脑没有可用的 Python，脚本会下载并打开 Python 安装程序；安装完成后按终端提示继续。
4. 服务就绪后会自动打开浏览器。

### 4. 启动说明

- 默认地址是 `http://127.0.0.1:8000`。
- 如果 8000 端口已占用，程序会自动选择 8001～8099 中的可用端口。
- 健康检查地址是 `http://127.0.0.1:8000/api/health`；若使用了其他端口，请同步替换端口号。
- 首次启动需要下载运行依赖，耗时取决于网络；以后会复用项目 `runtime/` 中的本地环境和缓存。
- 关闭启动脚本的控制台或终端窗口即可停止本地服务。

启动脚本默认使用适合中国大陆网络直连的下载源。高级用户可在启动前通过 `PIP_INDEX_URL`、`VIDEO2TEXT_PYTHON_URL`、`PLAYWRIGHT_DOWNLOAD_HOST` 和 `PLAYWRIGHT_BROWSERS_PATH` 更换可访问的镜像或缓存目录。

## 使用指导

### 第一次使用：登录 B站并自动获取 Cookie

程序不会替你输入账号、密码或完成扫码，登录操作始终由你本人完成。

1. 首次打开页面时，点击“打开B站登录窗口”。
2. 在程序打开的独立 Chromium 窗口中，自行扫码或输入账号完成 B站登录。
3. 确认窗口中已经显示登录状态，并保持这个 B站窗口打开。
4. 回到工具页面，点击“提取并保存Cookie”。
5. 程序会自动读取登录状态，只保留以下 6 个字段并保存到当前浏览器的 IndexedDB：

   `SESSDATA`、`bili_jct`、`DedeUserID`、`DedeUserID__ckMd5`、`bili_ticket`、`bili_ticket_expires`

6. 提取成功后，程序会关闭登录窗口并进入主页面。

如果之后出现 Cookie 失效、未登录、HTTP 403 或 HTTP 412，请打开右上角“设置 → 本地Cookie值 → 重新获取”，重新完成以上步骤。

### 配置两个模型

打开右上角“设置 → 模型配置”。两个模型用途不同，都需要配置。

| 配置 | 用途 | 要求 |
| --- | --- | --- |
| 音频转文字模型 | 直接读取 MP3，把音频逐段转成文字 | 必须真正支持音频输入，普通纯文本模型不可用 |
| 文稿优化模型 | 对照 B站字幕和音频转写稿，生成最终 Markdown | 支持 OpenAI-compatible Chat Completions 的文本模型 |

音频转文字模型有两种识别方式：

- **OpenAI Compatible 需要多模态模型**：通过 `/chat/completions` 发送 Base64 MP3。`API Base URL` 通常填写到 `/v1`，例如 `https://api.example.com/v1`。模型必须支持 `audio_url` 音频内容。
- **AIStudioToAPI Gemini 原生：Files API**：先上传 MP3，再调用 Gemini 原生流式接口。`API Base URL` 填 AIStudioToAPI 服务根地址，例如 `http://localhost:7860`，不要手动加 `/v1/chat/completions`。

各字段填写方法：

| 字段 | 填写说明 |
| --- | --- |
| API Base URL | 你的模型服务地址；必须以 `http://` 或 `https://` 开头 |
| API Key | 模型服务商提供的密钥 |
| Model | 模型 ID，可手动填写，也可先点击“获取模型”后选择 |
| Temperature | 建议从 `0`～`0.3` 开始，减少转写和校对时的自由发挥 |
| Stream | 建议保持开启，长内容返回更稳定 |

填写后分别点击两个模型卡片中的“保存配置”。“获取模型”只是读取服务商返回的模型列表，不能保证列表中的每个模型都支持音频；第一模型仍需选择明确支持音频输入的型号。

### 开始转换

1. 在首页粘贴 B站分享文本、视频链接或 BV 号。
2. 点击输入框右侧的开始按钮。
3. 保持本地服务窗口和当前网页开启，等待任务完成。
4. 如果视频没有字幕，可按页面提示选择“跳过字幕继续”。
5. 完成后可下载或复制 Markdown，并可展开查看字幕、音频转写稿和完整日志。

长视频会产生多个模型请求，耗时、费用和成功率取决于视频长度、网络和模型服务商限制。当前多P视频只处理链接所指向的分P；如需处理其他分P，请分别提交对应链接。

## 数据隐私说明

- 模型配置、API Key、精简 B站 Cookie 和历史记录保存在当前浏览器的 IndexedDB 中，不写入项目源码。
- B站完整 Cookie 不会返回前端或写入日志；本地专用登录 Profile 保存在 `runtime/browser-profile/`。
- API Key 和精简 Cookie 只在任务需要时发送给本机 FastAPI 后端；后端不会把它们写入持久文件，并会对日志中的常见密钥格式进行脱敏。
- 音频和中间文件临时存放在 `data/temp/`，任务完成、失败、取消或被判定为 abandoned 后会尝试清理。
- 选择第三方模型服务时，音频、字幕或转写文本会发送到你填写的 API 服务商。请在使用前阅读该服务商的隐私政策和数据保留规则。
- “导出”文件包含模型配置、API Key、精简 Cookie 和历史正文，属于敏感备份。请勿发送给他人或上传到公共平台。
- 清除浏览器站点数据会删除本地设置和历史。迁移浏览器或电脑前，请先导出备份。

## 常见错误排查

| 问题 | 处理方法 |
| --- | --- |
| 首次启动长时间没有完成 | 首次运行需要安装依赖和 Chromium。保持窗口开启并检查网络；失败后重新运行启动脚本会复用已下载内容 |
| Python 下载或依赖安装失败 | 安装 Python 3.10 及以上版本（推荐 3.12）后重试，或检查 `PIP_INDEX_URL`、`VIDEO2TEXT_PYTHON_URL` |
| Playwright Chromium 缺失或损坏 | 关闭本地服务后重新运行启动脚本；同时检查 `PLAYWRIGHT_DOWNLOAD_HOST` 是否可访问 |
| FFmpeg 不可用、MP3 转换或切片失败 | 重新运行启动脚本；确认磁盘空间充足，也可手动安装 FFmpeg 并加入 `PATH` |
| Mac 无法双击启动 | 执行 `chmod +x start-mac.command scripts/start-local.sh`，再右键 `start-mac.command` 选择“打开” |
| 页面显示“后端未连接” | 确认控制台/终端仍在运行，并访问当前端口的 `/api/health`；不要直接双击 `frontend/index.html` |
| B站登录窗口打不开 | 检查 Playwright Chromium、网络和安全软件；关闭残留 Chromium 进程后重试 |
| Cookie 提取不到 | 确认已在程序打开的独立 B站窗口中登录，并保持窗口打开，再回到工具点击“提取并保存Cookie” |
| HTTP 403、HTTP 412、未登录或 Cookie 失效 | 在“设置 → 本地Cookie值”中重新获取 Cookie，并先用普通公开视频测试 |
| 没有检测到字幕 | 视频可能没有 UP 主字幕或自动字幕，可按页面提示跳过字幕并仅使用音频转写 |
| 音频下载失败 | 先刷新 Cookie；确认视频可正常播放且不是付费、会员、私密或受限内容 |
| API Base URL 无效 | 必须以 `http://` 或 `https://` 开头；OpenAI-compatible 通常填到 `/v1`，Gemini Files API 填服务根地址 |
| API Key 无效或无权限 | 核对密钥、余额、模型权限和服务商区域限制，再点击“获取模型”测试连接 |
| 第一模型不支持音频 | 更换明确支持音频多模态的模型，或改用 AIStudioToAPI Gemini Files API |
| 请求体过大、限流或超时 | 稍后重试，检查服务商的文件大小、并发和速率限制，必要时更换模型服务 |
| 文稿优化失败或输出被截断 | 换用上下文更长、输出上限更高的文本模型；程序会自动重试和续写，但仍受服务商限制 |
| 导入失败 | 仅导入由本工具导出的 JSON，且不要手动修改文件结构；导入会覆盖当前全部本地数据 |
